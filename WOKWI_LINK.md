# Wokwi Simulation

The complete Smart Parking System was designed and tested using Wokwi.

## Open the simulation

[Click here to open the Wokwi project](https://wokwi.com/projects/472338695609496577)

The simulation demonstrates:

- Four ultrasonic parking-slot sensors
- Free/occupied slot detection
- Red and green LED indicators
- OLED display
- Parking-full buzzer
- Serial Monitor output
